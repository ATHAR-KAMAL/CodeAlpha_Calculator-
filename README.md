# CodeAlpha_Calculator-
A responsive calculator built with HTML, CSS, and JavaScript, featuring basic arithmetic operations, decimal calculations, delete and clear functions, responsive design, and interactive button effects.

Keyboard          Action
--------------------------------
0 - 9             Numbers
+                 Addition
-                 Subtraction
*                 Multiplication
/                 Division
.                 Decimal
Enter             Equals
Backspace         Delete
Escape            Clear

So we can type
25 * 4
and press Enter → 100 ✅
